## 6. アニメーション方針

### 6-1. 基本ルール

| 項目 | 値 |
|------|-----|
| duration上限 | 300ms |
| easing | ease, ease-in-out |
| 使用プロパティ | transform, opacity のみ（compositor props） |

### 6-2. 禁止事項

- レイアウトプロパティ（width, height, top, left）のアニメーション禁止
- 過剰なパララックス効果
- 自動再生アニメーション（prefers-reduced-motion考慮）

### 6-3. 使用箇所

| 箇所 | アニメーション |
|------|---------------|
| スクロール表示 | fade-in + translateY(20px) |
| ホバー | opacity 変化, scale(1.02) |
| アコーディオン | max-height + opacity |
| タブ切り替え | opacity + translateX |
