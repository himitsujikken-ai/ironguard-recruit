## 1. プロジェクト概要

### 1-1. 背景

アイアンガードコーポレーション株式会社（IGC）は、元オリンピック日本代表が率いる格闘家によるプロフェッショナル警護集団。現在の採用ページ（recruit.html）は提案書の内容を約93%実装済みだが、以下の改善余地がある。

### 1-2. 目的

1. 提案書で指摘された未実装項目の完了（FAQ追加、キャリアパス拡充）

3. コードの品質向上（SEO強化、構造化データ、パフォーマンス最適化）
4. フォーム送信機能の実装（現在は静的HTMLのみ）

## 4. 技術制約

### TC-001: 既存構成の維持

- **制約:** 静的HTML/CSSサイトの構成を維持する
- **理由:** クライアントの運用負荷を最小限に保つため
- **影響:** JavaScript使用は最小限（フォーム処理・UI操作のみ）

### TC-002: ホスティング

- **制約:** Vercelでのデプロイを継続
- **理由:** 既存のデプロイ環境を活用
- **影響:** サーバーサイド処理が必要な場合はVercel Functionsまたは外部サービスを使用

### TC-003: ファイル構成

- **制約:** 現行の5ページ構成を維持
  - index.html / recruit.html / about.html / company.html / contact.html / style.css
- **理由:** 既存サイトのURL構造を保持

## 5. ユーザーストーリー

### US-001: 格闘技経験者の求職者

> 格闘技経験者として、引退後のキャリアを模索しています。IGCの採用ページで具体的な給与条件と研修内容を確認し、自分のスキルが活かせることを確認した上で応募したい。

### US-002: 未経験の求職者

> 格闘技の経験はないが警備業界に興味があります。未経験でも応募可能か、どんな研修があるか、実際に働いている人の声を見て安心した上でエントリーしたい。

### US-003: クライアント（IGC人事担当）

> 応募者の基本情報と格闘技経験を効率的に収集し、適切な職種にマッチングしたい。フォームからの応募をメールで即座に受け取りたい。
